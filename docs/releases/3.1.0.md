Stable promotion from `dev` snapshot `96234021b5d743d1b730875b9b46de9fba2a7633`; comparison base `main` snapshot `58ab0b98d2d0def8e49dced705c7b566936723ec`. ## Scope and trial-use evidence

This release adds ERD, Class/interface, Tree, Timeline and Waterfall to the five existing diagram types. It promotes default Live motion, type-specific choreography, readable card styling, bounded automatic route/label recovery, structured authoring diagnostics, source verification, reader navigation and export/clipboard/Windows portability fixes. The complete change history is in [CHANGELOG](../../CHANGELOG.md#310--2026-10-14).

At merged-dev `d5806a6f8d05900fab175b832020f2da32f4152f`, three independent authors generated all ten types for three real local projects. Automated first drafts passed 27/30; final `validate`, `deliver`, strict provenance `check` and real-browser `browser-check` gates passed 30/30. Original drafts and repairs were retained outside this public repository. All 30 final diagrams had matched 1440×900 light/dark screenshot inspection; an independent Live → Still → Live smoke passed 30/30 without changing authored geometry or reporting page errors. This was concurrent discovery, not a controlled speed comparison. Source-semantic corrections were recorded separately from automated acceptance. The maintainer accepted the release direction after reviewing these outputs.

The later #910 change adds a localized link inside the reader-opened Guide and a docs navigation star. The promotion rebuild refreshes all affected examples, gallery, comparison output, README motion proof and canonical archive. Equivalent spaced SVG path commands prevent the version-identity checker from mistaking minified path coordinates for a release version.

## Known limitations

- Some long Sequence diagrams need scrolling; floating controls can overlap a message at particular initial viewport positions.
- Some Dataflow inputs share a long visual corridor, weakening path distinction despite passing automated geometry checks.
- Long Class generic types can leave a closing angle bracket on a separate line. Some automatic layouts leave excess whitespace, and the default Workflow legend may use agent terminology for another domain.
- Conceptual ERD entities and illustrative Timeline/Waterfall scenarios must be identified as such. No measured performance improvement is claimed.

These observations remain visible and are not reclassified as automated failures or silently removed from acceptance evidence. Publication exposes the tested product with these stated limitations.

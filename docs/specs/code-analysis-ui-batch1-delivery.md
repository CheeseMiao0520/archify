## 交付范围

- **U1 总览**：前三优先项显示具体源码路径/行号及任务生成器提供的维护影响；重复与项目规范未检查的提示直接可见；覆盖细节、分组及已接受项保留现有折叠入口。
- **U2 问题阅读**：事实之后先显示最多两个九行代码片段；随后提供建议及 AI 任务入口；关系图、指标及完整证据默认折叠。组件入口也能准备任务。
- **U3 源码**：问题片段定位到触发行，复杂度问题定位到最深嵌套；打开源码后同时标记函数区间和选中行，展开完整文件时保留标记；无源码给出重新分析/编辑器阅读提示。
- **U4 交接**：Prepare AI task 展开任务预览，提供 Copy AI task、Download .md、Check again；使用 Claude 生成器返回的同一 Markdown，不在前端另拼任务。复制失败时选中只读预览供手动复制。
- **U5 状态**：在线请求使用现有鉴权；复制或下载前重新获取并校验证据。valid、changed、missing、unverifiable、captured 分别说明。网络不可用时明确降级到未校验的捕获快照；HTTP 403/409/422 保留错误和重试入口，不用快照遮掩拒绝。比较显示 no longer detected，不兼容或缺少比较上下文时展示原因。
- **U6 体验检查**：1440×900、1280×720、390×844 截图检查；长路径和函数名换行；窄屏分析模式收起非必要的 preset/present 工具按钮以保留主题、导出与分析开关。增加可见焦点、问题标题焦点、源码返回焦点及键盘打开任务入口。

本次未修改检测规则、严重级别或自动重构行为。UI 导出操作不会应用代码修改或执行项目测试。
